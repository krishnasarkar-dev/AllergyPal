## 📖 The Story: Why I Built This for Rahul

My roommate **Rahul** deals with severe, life-threatening tree nut and lactose allergies. Living and dining together, I saw firsthand how exhausting and anxiety-inducing every single meal can be:
- Reading tiny, confusing ingredient labels at supermarkets.
- Wondering if an innocent-looking smoothie or pasta contains almond milk, cashew paste, or hidden whey.
- Having to constantly double-check whether a recipe is safe to cook at home.

I built **AllergyPal** as a personal weekend project to make Rahul's life easier, safer, and completely stress-free. It uses **open-source AI** to parse recipe ingredients, detect hidden allergens in milliseconds, and instantly recommend 100% safe, delicious substitutes.

---

## ✨ Key Features

- **🛡️ Custom Allergen Shield:** Pre-configured for Rahul's allergies (Tree nuts, Peanuts, Dairy/Lactose) with support for Gluten, Soy, and Shellfish toggles.
- **⚡ Instant Recipe Scanner:** Paste any ingredient list, restaurant menu item, or recipe to immediately identify danger ingredients.
- **🔄 Smart Safe Substitutions:** Automatically suggests tested 1:1 culinary replacements (e.g. replacing almond milk with oat milk, or peanut butter with sunflower seed butter).
- **🍲 1-Click Safe Meal Generator:** Generates allergen-free breakfast, lunch, and dinner recipes powered by open-weight AI prompts.
- **🔒 100% Local & Private:** Runs entirely on-device with zero cloud server dependencies, guaranteeing that medical and dietary data is never leaked or tracked.

---

## 💡 Why Open Innovation Matters Here

When building assistive health tools for loved ones, **open-source AI** is fundamentally superior to closed, proprietary APIs:

1. **Absolute Health Privacy:** Rahul's personal medical conditions and dietary restrictions never touch a remote commercial server or get fed into advertising algorithms.
2. **Offline Resilience:** Works in supermarket basements, remote hiking trips, and places with spotty or zero cell reception.
3. **Zero Financial Gatekeeping:** No monthly API subscription fees or sudden rate limits when scanning dozens of recipes each week.
4. **Verifiable Safety:** Anyone can inspect the open code and allergen mappings to verify there are no hallucinations or missed hazards.

## 🚀 Quick Start / Local Setup

No build step or complicated toolchain required. It runs purely in the browser!

```bash
# Clone the repository
git clone https://github.com/krishnasarkar-dev/AllergyPal.git

# Navigate into the project directory
cd AllergyPal

# Open index.html in any browser
xdg-open index.html   # Linux
open index.html       # macOS
start index.html      # Windows
```
